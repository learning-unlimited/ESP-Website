{% extends "main.html" %} {% load modules %} {% comment %} Shared base template for student and teacher registration pages: the main pages and the pages of the checklist steps. Pages a user opens on purpose and then leaves (the class registration interfaces and the class tools, such as class status, rosters and documents) extend main.html instead, so they show no checklist. Templates extending it place their content in the module_content block; the main pages also use module_header for their full-width heading. In registration, the registration checklist (and any other registration requirements) is shown, with a progress bar, in a sticky column beside the content when there is room and above it otherwise, unless the registration's "Show checklist" setting is off. Themes whose main.html has a sidebar_extra block can put the list there instead, via a checklist_in_sidebar theme setting (as bigpicture does). Elsewhere (e.g. templates shared with account pages) the content renders as a plain page.
