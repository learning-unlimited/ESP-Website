ILP (Gurobi) Lottery — click to expand

The Integer Linear Programming (ILP) lottery is a newer option which will create better-optimized schedules than the legacy lottery. It works by creating an objective function — that is, a function which takes in the set of all class assignments and gives a numerical output indicating how good the assignments are — and using an optimizer (Gurobi) to search for a scheduling result as close as possible to the optimal objective function.

By default, the objective function prioritizes:

  1. students getting as many of their ranked/starred classes as possible (with higher value for higher-ranked classes),
  2. avoiding sad students, with a penalty for each student with a particularly empty schedule,
  3. avoiding sad sections, with a penalty for each section with particularly low enrollment, and
  4. equitable distribution of classes across students, with each student's nth assigned class worth a bit more than their n+1th assigned class so the optimizer tends to even out the number of classes among students.

Legacy Lottery — click to expand

The legacy lottery is kept as a fallback option. In the case of issues with the ILP lottery (such as Gurobi license issues), this is at least something you can use to assign students to classes, although you should expect lower-quality results. It's usually a good idea to run this one multiple times and save the result with the best statistics. After saving the results, you usually will want to manually "unscrew" the schedules of students who were unlucky and ended up very far from a full schedule despite submitting plenty of preferences.
