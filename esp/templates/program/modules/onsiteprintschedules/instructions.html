Print student schedules

Using this tool you can print student schedules for students on the fly.
To use this tool as intended you must:

  1. Get a computer that can reliably sit and be plugged into a printer
  2. Update firefox to the most recent version on the computer
  3. Install a printer, and make SURE it's default (at least in Firefox)
  4. Use firefox :-D
  5. Set up the printer as default:
    1. Goto about:config and type `print_printer'. Enter the string title (exactly) for the {{ settings.ORGANIZATION_SHORT_NAME }} Printer.
    2. Type in print.always_print_silent into the search bar, and make it a new boolean variable if it doesn't already exist; then set it to TRUE.
    3. Make print.print_duplex as a number variable if it doesn't already exist. Set it to 0 for single-sided, 1 for double-sided with long-edge binding, and 2 for double-sided with short-edge binding (you'll usually want it set to 1).
    4. While you're at it, you might as well make print.print_color FALSE.
    5. Note that the print_duplex and print_color settings might be overridden in per-printer config settings (e.g. print.printer_Brother_HL-2280DW.print_duplex), so if the settings don't seem to be working, check your per-printer settings as well.
    Now your printer will now automatically print from firefox. Test this by printing this page. Notice it shouldn't open a dialog box or anything.
  6. Now you should be ready to go to the next page!
MAKE SURE YOU DO THIS ON ONE COMPUTER. IF YOU DON'T KNOW WHAT YOU ARE DOING, PLEASE GO BACK NOW!
